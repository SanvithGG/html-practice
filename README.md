# 🌐 Web Technologies & Full-Stack Practice

A structured repository containing Web Development practice files, topic-wise exercises, CSS styling demos, JavaScript programming concepts, and complete web page replicas.

---

## 📂 Repository Structure

### 📄 1. HTML (`HTML/`)
Core HTML structure, semantics, multimedia, and form controls.
- **`Attributes/`**: HTML element attributes, marquee behaviors, formatting tags (`Attribute.html`).
- **`Basic_Structure/`**: Boilerplate structure, headings, paragraphs, and text formatting (`page.html`).
- **`Forms/`**: Form validation, input types, radio/checkboxes, fieldsets, and legends (`Forms.html`).
- **`Hyperlinks/`**: Anchor tags, external/internal bookmarks, relative & absolute links, mailto/tel protocols, and clickable icon navigation (`Hyper link.html`, `internalHyperlink.html`, `icons/`).
- **`Lists/`**: Ordered, unordered, and nested list structures (`list.html`).
- **`Media/`**: Embedding images, videos, audio players, Google Maps iframes, and animated GIFs (`Media.html`, `images/`, `audios/`, `Vedios/`, `gif/`, `hhttp/`).
- **`Tables/`**: HTML tables with rowspans, colspans, cell padding, spacing, rules, and alignment (`tables.html`).

---

### 🎨 2. CSS (`CSS/`)
Cascading Style Sheets styling rules, modern layouts, and visual effects.
- **`Animation/`**: Keyframe animations, movement, and transitions (`Index.html`, `style.css`).
- **`Background_Properties/`**: Background colors, background images, repeat, position, size, and attachment (`Backgroundproperties.html`, `Backgroundproperties.css`).
- **`Border_Properties/`**: Border styles, widths, colors, and outline designs (`borderproperties.html`, `borderproperties.css`).
- **`Box_Model/`**: Padding, margins, border bounds, content sizing, and box-sizing (`boxmodel.html`, `boxmodel.css`).
- **`Color_Properties/`**: Named colors, RGB decimal, and Hexadecimal representations (`Colorproperty.html`, `Colorproperty.css`).
- **`Combinators/`**: Descendant, child (`>`), adjacent sibling (`+`), and general sibling (`~`) selectors (`combinators.html`, `combinators.css`).
- **`Display_Properties/`**: Block, inline, inline-block, flex, and grid display modes (`displayproperties.html`, `displayproperties.css`).
- **`External_CSS/`**: External stylesheet linking and global selector rules (`externalcss.html`, `external.css`).
- **`Filter_Properties/`**: Image filters (grayscale, blur, brightness, contrast) (`filterproperties.html`, `filterproperties.css`).
- **`Gradient_Properties/`**: Linear and radial gradients (`index.html`, `style.css`).
- **`Internal_Inline_CSS/`**: Embedded `<style>` tags, inline style attributes, element/id/class selectors (`internalscc.html`, `style.html`).
- **`List_Design/`**: Custom styling for bullet points and ordered counters (`index.html`, `style.css`).
- **`Position_Properties/`**: Static, relative, absolute, fixed, and sticky positioning (`positionproperties.html`, `positionproperties.css`).
- **`Pseudo_Selectors/`**: Pseudo-classes (`:hover`, `:first-child`, `:nth-child`) and pseudo-elements (`index.html`, `style.css`).
- **`Responsive_Nav/` & `Responsive_Layout/`**: Media queries, hamburger navigation, responsive flex cards, and viewport scaling.
- **`Shapes/`**: Pure CSS geometry (circles, ovals, triangles, leaves, targets, Pokeball) (`shapes.html`, `shapes.css`).
- **`Text_Properties/`**: Font families, text alignment, decoration, transform, spacing, and shadows (`textprorerties.html`, `textprorerties.css`).
- **`Transform_Properties/`**: 2D/3D transforms (translate, rotate, scale, skew) (`transformproperties.html`, `transformproperties.css`).

---

### ⚡ 3. JavaScript (`Java Script/`)
Core JavaScript language features, syntax, and DOM scripts.
- **`Basic_Syntax/`**: Script integration, console logs, basic execution flows (`basic.html`, `basic.js`, `demo.html`).
- **`Keywords_and_Variables/`**: Scope rules, declarations (`var`, `let`, `const`), and variable hoisting (`keyword.js`).
- **`Data_Types/`**: Primitive types (Number, String, Boolean, BigInt, Symbol, Undefined, Null) and reference types (`Datatype.js`).
- **`Conditionals/`**: Conditional decision logic (`if`, `if-else`, `else if`, nested conditions, ternary operators) (`controlif.js`).
- **`Loops/`**: Iterations using `for`, `while`, and `do-while` loops (`loop.js`).
- **`Functions_and_Methods/`**: Function declarations, function expressions, arrow functions, and method invocations (`Function.js`, `index.html`).
